# Старт для нового чата ChatGPT

**Прежде чем трогать Windows или GitHub:** прочитай [полный протокол](docs/CHATGPT_TRANSFER_PROTOCOL.md) через подключённый GitHub-плагин. Это главный источник инструкций и ограничений. Репозиторий документации: `AlexPastukhh/test`.

## Готовый промпт (скопируй в новый чат)

> Работаем с локальными Git-репозиториями Windows через подключённый туннель и GitHub-плагин.
>
> Сначала прочитай `AlexPastukhh/test/docs/CHATGPT_TRANSFER_PROTOCOL.md` с помощью GitHub-плагина и сверяй все операции с ним. Не считай старые `file_id` или снапшоты актуальными.
>
> Цель: получить актуальный **локальный** снапшот указанного мной репозитория, включая нужные незакоммиченные и неотслеживаемые файлы; передать через GitHub Actions Artifact в файловую систему **этого** чата; работать с копией автономно; создать Git-compatible патч; проверить и применить его обратно на Windows **одним вызовом туннеля**.
>
> Не используй `git archive HEAD` или GitHub checkout вместо локального снимка. Не коммить мои рабочие изменения, не перезаписывай чужие правки, не публикуй секреты и не загружай реальные проекты в публичный посредник.
>
> При получении ZIP проверь, что он **реально появился в файловой системе ChatGPT** и распакован. Не путай ссылку с файлом. Для обратного пути предпочитай прямую передачу содержимого патча в PowerShell через туннель; GitHub-публикация патча не нужна при небольшом размере.
>
> Перед применением проверь хеши исходных файлов и `git apply --check`. При расхождении остановись. Отчитывайся о каждом проверенном этапе, а не о предположении. Коммиты и push результата делай только по моему отдельному запросу.

- Имя Artifact: `chatgpt-snapshot`
- Скачивание в чат: GitHub-плагин `fetch_workflow_run_artifacts` → `download_workflow_artifact`
- Содержимое Artifact: вложенный `local-snapshot.zip` — распаковать оба слоя.
- Обратная передача: патч → Base64 или другой безопасный аргумент → Windows PowerShell → `git apply --check` → `git apply`.
